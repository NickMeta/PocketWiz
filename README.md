# PocketWiz – landningssida (diskussionsunderlag)

Första versionen av landningssidan, för Nicklas och David. En enda fil: `index.html`.

## Visa sidan
- Lokalt: öppna `index.html` i webbläsaren.
- GitHub Pages: lägg filen i repots rot, gå till Settings → Pages, välj grenen `main` och mappen `/ (root)`.

Knappen **"Visa varför sidan ser ut så här"** nere till höger visar researchnoteringar med källor vid varje sektion.

## Platshållare att byta ut
| Var | Vad | Hur |
| --- | --- | --- |
| Huvudfilmen | Referensfilm (Dext) | Byt `data-video` på `.player` till er egen YouTube- eller Vimeo-embed |
| Kundporträtt | Referensfilm | Byt `data-video` på `.vid-mini` |
| Citat och porträtt | Text inom hakparentes | Riktiga citat från testgruppen, med lov |
| "Används redan av 14 frilansare" | Påhittad siffra | Riktig siffra eller ta bort |
| Foto på grundarna | Randig yta | Eget foto, gärna från en inspelning |
| Skärmbilder | Ritade i HTML | Riktiga skärmbilder ur appens testläge |
| Pris 59/79 kr i månaden | Förslag | Beslut om prismodell |
| support@pocketwiz.se | Påhittad adress | Riktig adress och domän |

## Sidans ordning
1. Rubrik, en knapp, socialt bevis vid knappen, kvittodemo
2. Problemet (igenkänning)
3. Huvudfilmen (klicka för att spela)
4. Fem skäl utöver kvittot
5. Så går det till, tre steg
6. Kundröster
7. Grundarnas berättelse
8. Pris
9. Frågor och invändningar
10. Samma knapp igen
